Methods and interpretation guidance

Core-clustering contexts

Core SNP clustering is performed within the configured ordered Core-clustering context. Depending on the configuration, the context may represent sequence type, the main epidemiological variable, a secondary variable, or an ordered combination of variables. A context is eligible for Core clustering when it contains at least two isolates.

Initial data-driven K clustering

For each eligible context, SNP2Cluster-Py uses the supplied Core SNP-distance matrix to perform an initial data-driven clustering step. Candidate multi-cluster solutions are assessed using silhouette-based diagnostics where the data support comparison between two or more initial clusters.

An initial K of 1 is a valid data-driven result when the SNP-distance data support one initial group. This includes contexts containing multiple isolates with one distinct SNP-distance profile. A numerical silhouette width is not defined for a one-cluster solution, but the K=1 group remains eligible for the subsequent SNP-cutoff refinement step.

SNP-cutoff refinement

After initial K assignment, each initial group is evaluated using the unscaled pairwise Core SNP distances and the configured SNP cutoff. Pairwise comparisons above the cutoff provide points for splitting the initial group according to the implemented chain-refinement logic. Only final Core SNP clusters containing at least two isolates are retained and reported.

Context-aware cluster labels

Final Core SNP cluster labels retain the configured context so that cluster identifiers remain interpretable across analytical groups. Core SNP cluster membership therefore reflects both the selected analytical context and the post-K-selection SNP-cutoff refinement.

Transmission clustering

In Transmission mode, SNP2Cluster-Py subsequently integrates Core SNP cluster membership with the configured epidemiological grouping, specimen-collection dates, SNP threshold and temporal threshold. Transmission-cluster assignments should be interpreted alongside the transmission scatterplots and the available epidemiological information.

Interactive networks

Minimum-spanning-tree and transmission-network edges visualise genetic relationships between isolates. Network connections are analytical visualisation aids and must not be interpreted as confirmed direct transmission events.

Important interpretation limitation

This report summarises analytical outputs produced by SNP2Cluster-Py. Results should be interpreted alongside the effective configuration, laboratory information, epidemiological metadata, sampling strategy and relevant public-health context.
